# Küşt logo — Square K

A K built from chessboard squares. The arms run on the diagonals, the way a
bishop moves, and the gold square is the last move, as on the board in the app.
In the wordmark the square K takes the place of the typed K, so the logo reads
"Küşt" without repeating itself.

## Colours

| Name | HEX | Where |
|---|---|---|
| Gold | `#FFBB00` | Last move square, ü dots, ş tail, icon tile |
| Ink | `#17181A` | Squares and letters on light |
| Light ink | `#F2F0EA` | Squares and letters on dark |
| Paper | `#F7F5F0` | Preferred light background |

On the gold tile the last-move square turns white; gold on gold would vanish.
In one colour the last-move square takes the same colour as the rest.

## Rules

- **Clear space:** one square (a fifth of the K's height) on every side.
- **Minimum size:** symbol 16 px (use the small cut below 32 px); wordmark 64 px wide.
- **Don't:** round the squares, add gaps or outlines, recolour the last move
  anything but gold or white, rotate or mirror it (a mirrored K is not a K),
  set "Küşt" in a font next to the symbol (the wordmark already contains it).

## Notes

- The ü, ş and t are the app's existing wordmark letters, outlined; only the K is new.
- Trademark clearance has not been checked.
